# Portfolio

This is a simple portfolio website project.

## Features
- Responsive layout
- Dark theme styling
- Project showcase section
- Contact form

## Files
- `index.html`: Main HTML file for the portfolio
- `style.css`: Stylesheet for layout and dark theme
- `script.js`: JavaScript for interactivity

## Usage
Open `index.html` in your browser to view the portfolio.

## Customization
- Update your profile image and details in `index.html`
- Add or modify projects in the projects section
- Adjust styles in `style.css` as needed
